## Hi there 👋, I'm Krong!

**你好，我是開發者趙成珉（Seongmin Jo）。**

面對初次接觸的技術，我感受到的是興趣，而不是壓力。 <br>
我透過官方文件與實際程式碼深入研究陌生的 API 與架構，並將這些心得留在部落格與 commit 紀錄中。 <br>
